# NEXUS SEO — Stage 1

Free-first, static technical SEO dashboard and bounded Python crawler for Bravo Dispatch LLC.

## Contents
- `scripts/audit.py` — standard-library, same-host crawler (30 pages by default)
- `docs/index.html`, `docs/styles.css`, `docs/app.js` — static dashboard
- `docs/data/report.json` — generated by the audit; intentionally absent until the first run
- `.github/workflows/audit.yml` — daily and manual audit workflow

## Quick start in GitHub (no local install)
1. Create a new **public** GitHub repository called `nexus-seo` (do not use the existing Bravo Dispatch website repository).
2. Upload **all files and folders**, preserving paths, including the hidden `.github/workflows/audit.yml` file. The ZIP is for extraction before upload, not for uploading as one ZIP file.
3. In the repository, open **Actions → NEXUS SEO Daily Audit → Run workflow**. Wait for a green run. This creates `docs/data/report.json`.
4. Open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/docs**, then **Save**. (Use your actual default branch if different.)
5. Open `https://YOUR-GITHUB-USERNAME.github.io/nexus-seo/` after Pages publishes. Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
6. Open **Actions** after a day to confirm the scheduled run. GitHub schedules can be delayed or disabled for inactive public repositories.

## Permissions / troubleshooting
- In **Settings → Actions → General → Workflow permissions**, set **Read and write permissions** if the workflow cannot push `report.json`. This grants repository content write access to the workflow; use a dedicated repository.
- If Actions are disabled, enable them for this repository.
- If Pages does not load, confirm repository visibility and Pages configuration.
- If the report fails, inspect the workflow logs for DNS, connection or server errors. Do not interpret a failed crawl as a website SEO problem.
- The dashboard is public. Do not add credentials, private data or Search Console exports to `docs`.

## Run locally (optional)
Requires Python 3.10+. From repository root: `python scripts/audit.py`.
For local dashboard preview: `python -m http.server 8000 --directory docs`, then visit `http://localhost:8000/`.

## Scope and limitations
- Audits up to `MAX_PAGES` (1–100) same-host HTML URLs and uses a 0.15s pause between page fetches.
- Does not execute JavaScript; a client-rendered site may require a browser-based crawler in a future stage.
- Does not interpret robots.txt crawl restrictions. Only run on sites you own or have permission to audit.
- Internal links not crawled due to the page limit are not checked; this is **not** exhaustive broken-link detection.
- No Google Search Console integration, keyword volume, rankings, or AI generation in Stage 1.
- The internal health score is heuristic, not an official Google score.
- `robots.txt` and `sitemap.xml` availability is checked by HTTP status only.
- Daily schedule depends on GitHub Actions availability and free quotas; it is not a guaranteed execution time.
